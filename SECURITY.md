# Security

## Reporting

Do not open a public issue containing credentials, personal paths, music files, or other sensitive information. Use GitHub's private security advisory feature when available.

## Local data

- Audio and NCM files remain on the local computer.
- Automatic lyrics sends only track title, artist, album, and duration to LRCLIB.
- The application does not download music and does not upload audio.
- NCM files should be processed only when lawfully obtained for personal use.

## Credentials

Never commit GitHub passwords, personal access tokens, cookies, or credential-manager exports. The repository is configured to exclude user data, virtual environments, local launch shortcuts, and temporary files.
